# 📊 Sales Data Analyzer

## 🚀 1. Project Overview
Sales Data Analyzer is a Python-based project that analyzes sales data stored in a CSV file. It uses Pandas to process data and Matplotlib to display charts and graphs.

## 🎯 2. Project Objectives
- 📂 Read sales data from a CSV file.
- 💰 Calculate total sales revenue.
- 🧾 Count total transactions.
- 📦 Calculate total units sold.
- 🏆 Identify the best-selling product.
- 🌍 Analyze sales by product and region.
- 📈 Display sales data using graphs.

## ✨ 3. Features
- 📥 CSV file reading.
- 💵 Sales summary calculation.
- 🛍️ Product-wise sales analysis.
- 🗺️ Region-wise sales analysis.
- 🥇 Top-selling product identification.
- 📊 Bar chart and line chart visualization.
- ⚠️ Handling of invalid or missing data.

## 🛠️ 4. Technologies Used
- 🐍 Programming Language: Python 3
- 🐼 Library: Pandas
- 📉 Library: Matplotlib
- 📄 Data Format: CSV

## ▶️ 7. How to Run the Project

Open the project folder in VS Code and open the terminal.

Run the program using:

```bash
python one.py
```

To run a particular test case:

```bash

```

Choose an option from the displayed menu and press Enter.
